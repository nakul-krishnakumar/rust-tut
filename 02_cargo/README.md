
- `cargo new hello_world` : create new cargo project.
- `cargo init`: convert an existing project to cargo project.
- `cargo build`: build a binary under `./target/debug/<proj_name>`.
- `cargo run`: build and run the binary in a single command.
- `cargo check`: checks your code to make sure it compiles but doesn't produce an executable.
- `cargo build --release`: compile with optimizations (for production). Might take longer. Creates executable in `target/release`
- `cargo add <package>`: add new dependencies.
